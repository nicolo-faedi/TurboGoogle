## About

Have you also run into Chrome's strange limit of 10 shortcuts? This is the solution.

The one and only...

## TURBO GOOGLE 🚀

The only turbo thing is the name. It is otherwise the classic Chrome new tab, but you can finally add as many shortcuts as you want.

- Unlimited, draggable and reorderable shortcuts
- Folders for organizing shortcuts
- Favicon support
- Multiple languages
- Dark and Light themes
- Customizable main text and logo
- Turbo palettes and customizable background
- Data stored locally and synchronized with Chrome

No extra account, no tracking, no unnecessary data collection. I DON'T CARE.

## Local development

Requirements: Node.js and Google Chrome.

```bash
npm install
npm test
npm run build
```

To load the extension in Chrome:

1. Open `chrome://extensions`
2. Enable Developer mode
3. Select **Load unpacked**
4. Choose the `dist/` directory
